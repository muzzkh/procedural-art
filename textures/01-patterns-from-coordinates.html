Textures 1

Patterns from Coordinates

A texture is the surface detail of a thing: the bricks of a wall, the grain of a plank, the weave of a cloth. A procedural texture is a function that answers one question, "what is at this point?", for any point you ask about. This lesson builds regular patterns from nothing but the coordinates of the point.

A texture is a function

An image texture stores an answer for every pixel. A procedural texture computes the answer when asked. You give it a position, by convention called u and v and running from 0 to 1 across the surface, and it returns a value. That value is usually a colour, but it can equally be a height, a roughness or a transparency (Textures 4).

This has consequences you can use:

  • No fixed resolution. Ask at more points and you get more detail, until the formula itself runs out.
  • Parameters instead of repainting. Mortar width, brick size and colour variation are numbers.
  • Every point is independent. The function may not look at its neighbours' answers, only at its own coordinates. This is the same constraint as a shader (Lesson 9), and every pattern here will run unchanged on a graphics card (the Shaders section).

All the examples in this section use the same few lines of plumbing: loop over the pixels, turn the pixel position into u and v, call texture(u, v), and store the result. Read the texture function and skip the rest.

Cells: floor and fract

Almost every regular pattern starts with the same two lines. Multiply the coordinate by the number of repeats you want. The whole-number part of the result, Math.floor, says which cell you are in. The fractional part, PA.fract, says where inside that cell you are, from 0 to 1.

  • The cell number is the same for every point in a cell, so it is used for decisions about the whole cell: which colour, which way up, present or missing.
  • The position inside the cell is used to draw the cell's contents. Whatever you draw there is repeated in every cell for free.

Patterns 0 and 1 use only the cell number. Patterns 2 and 3 use only the position inside the cell. Real textures use both.

Bricks: shifting rows and one random number per cell

A brick wall adds two ideas to the grid.

  • Offset rows. Before splitting u into cells, add half a cell to it on every other row. The row number comes from v, so it is known first.
  • Per-cell randomness. A hash turns the cell's two whole numbers into a repeatable random number. The same cell always gets the same number, so each brick has its own fixed shade, and the wall does not flicker when it is redrawn. You cannot use a stream of random numbers here (Lesson 2), because points are asked about in no particular order.

The distance to the nearest edge of the cell does the rest. Close to the edge is mortar. A little further in, the brick is darkened to suggest a rounded corner.

Set the variation to 0 and the wall looks printed. Set it to 1 and it looks neglected. Somewhere between is a wall. That one slider is most of the difference between a pattern and a material, and Textures 2 is about where such variation comes from.

Other grids: hexagons

Square cells are not the only choice. A honeycomb can be found with a trick: lay down two rectangular grids, the second shifted by half a cell in both directions, and for each point keep whichever grid's cell centre is nearer. The cells of nearest-centre regions are hexagons, for the same reason that Voronoi cells of evenly spread seeds are (Lesson 7).

As before you get two things for each point: an identity for the cell, hashed into a colour, and a position inside the cell, used to draw the border and a centre mark.

Layering two directions: a woven cloth

A tartan is two sets of coloured stripes, one running each way, with a rule for which is on top at each crossing. The stripes are a list of colours and widths called the sett. The rule here is a twill: a thread goes over two and under two, and each row starts one thread later than the one above, which produces the diagonal ribs you can see in denim.

Both ideas are small. The stripe colour is a lookup by position along one axis. The weave is a test on the sum of the two thread numbers. Change the seed for a new cloth.

Aliasing: when the pattern is finer than the pixels

A procedural texture has unlimited detail, and a screen does not. When a pattern changes faster than once every two pixels, sampling it at one point per pixel does not give a blurred version of the pattern. It gives a different, false pattern: coarse rings, crawling dots and moiré. This is aliasing, and the two-pixel limit is the Nyquist limit you met with sound in Special Topic 4.

The test pattern below is a set of rings that become finer with distance from the corner. On the left it is sampled once per pixel, and rings appear in the far corner that are not in the formula at all. There are three cures.

Supersampling
Sample several points inside each pixel and average them. It always works and costs that many times more. The middle panel uses 16.
Fading by frequency
If you know how fast the pattern is changing at a point, fade it to its average colour as that rate approaches the limit. It costs almost nothing, but you need to know the formula. The right panel does this.
Prefiltering
For image textures, store the image at full, half, quarter size and so on, each one properly blurred, and read from the size that suits the pixel. These pyramids are called mipmaps, and were introduced by Lance Williams in "Pyramidal Parametrics" (SIGGRAPH 1983).

In the examples above, the hard edges of the bricks and hexagons are aliased too: they are stair-stepped. The cure for an edge is the second one. Replace the hard test d < r with a smoothstep about one pixel wide (Maths 1, Lesson 9). Shaders 1 shows how the graphics card can tell you how wide one pixel is.

Tiling: a texture that joins itself

A texture is often repeated across a large surface, so its right edge must continue into its left edge and its bottom into its top. For patterns made of repeating parts the rule is simple: a whole number of repeats must fit across the tile. Two and a half waves cannot join. Two or three can.

The canvas shows the same tile four times. Move the first slider and the seams appear as breaks through the middle. Turn on whole numbers and they vanish for every setting. Special Topic 2 used the same idea for a textile repeat, and Textures 4 makes noise tile.

Key ideas

  • A procedural texture is a function from a position to a value. It may use only the position, never its neighbours' results.
  • floor of a scaled coordinate tells you which cell you are in. fract tells you where in the cell.
  • A hash of the cell number gives every cell its own repeatable random number.
  • The distance to the cell's edge gives borders, mortar and bevels.
  • Detail finer than two pixels aliases. Supersample it, fade it, or prefilter it.
  • A texture tiles when a whole number of repeats fits across it.

Common mistakes

  • Using a random stream for per-cell values. The result depends on the order pixels are visited in. Hash the cell number instead.
  • Mortar that is thicker one way than the other. Positions inside a cell run from 0 to 1 in both directions even when the cell is not square. Convert back to texture units before comparing distances, as TX1.2 does.
  • Negative coordinates. In JavaScript -3 % 2 is -1. If a pattern must work for negative positions, use ((n % m) + m) % m.

Textures challenge 1

A Pattern Sampler

Make a sheet of nine swatches, each a different regular pattern written as a function of u and v, in the manner of a book of fabric or tile samples.

Requirements

  • Nine swatches in a 3 × 3 sheet, each drawn by its own texture(u, v) function through one shared loop.
  • At least one pattern on an offset grid, one on a non-square grid, and one that layers two directions.
  • At least three patterns use a hash of the cell number, each for a different purpose: colour, rotation, size, or leaving a cell out.
  • No stair-stepped edges: every edge is softened over about one pixel, or the swatch is supersampled.
  • Every swatch tiles. Prove it by drawing one swatch of your choice four times.
  • No noise. This sheet is about structure. Noise is the next lesson.

Hints

  • Herringbone, basket weave, fish scales, hexagonal tiles, triangles, a quilt of rotated squares and a chain-link fence are all cell patterns.
  • Scales and roof tiles are an offset grid of discs in which each row covers the one above.
  • Rotate a cell's contents by rotating the position inside the cell about (0.5, 0.5) before you draw.

Stretch goals

  • Give the whole sheet one seed that changes all nine swatches while keeping them recognisable.
  • Add one swatch on a triangular grid.

You are done when

  • Someone can name the material or object each swatch suggests.
  • Changing the number of cells in any swatch never breaks it.
