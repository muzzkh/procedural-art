Reference

Glossary

The terms used in this course, in plain words, with the place each is introduced. L is a lesson, M a maths page, TX a textures lesson, SH a shaders lesson, IL an illusions lesson, S a special topic, P a 3D printing lesson, T three.js, B Blender, W web design.

A to C

Acceleration
How much velocity changes each step. Forces act here. L5
Add-on
A Python package that adds tools to Blender's interface. B4
Additive blending
Overlapping colours add their brightness, like light. L4, T2
Albedo
The colour of a surface itself, with no light or shadow in it. Also called base colour. TX4
Algorithm
A precise, step-by-step procedure for doing something.
Aliasing
False patterns that appear when detail finer than two pixels is sampled once per pixel. TX1, SH1
Ambient occlusion
The darkening of creases and hollows, where light from all around cannot easily reach. TX4, SH3
Amplitude
How far a wave swings from its centre. L4
Analyser
A Web Audio node that reports how loud a sound is in each band of pitch. S1
Anisotropy
Behaving differently in different directions, such as diffusion that is faster one way. TX3
Aperture problem
Through a small window, a moving edge shows only the motion at right angles to itself. IL3
Arc length
Distance measured along a curve, used to space things evenly on a path. M3
Assimilation
A patch taking on some of the colour of thin stripes that cross it. The opposite of contrast. IL1
Attract mode
What an interactive piece does when nobody is touching it. S1
Attractor
A point that pulls particles toward it. Also the shape a chaotic system settles onto. L5, M4
Autostereogram
A single picture that gives each eye a different view when you look through it, so that depth appears. IL4
Barycentric coordinates
Weights that add up to 1, giving a position inside a triangle as a blend of its corners. M6
Basis
The set of arrows a coordinate system is built from. Any two that are not along the same line give a grid. M6
Bézier curve
A smooth curve defined by control points, built from repeated interpolation. M5
Bleed
Artwork extended past the trim line so that a print can run to the edge. S3
Boids
Craig Reynolds's flocking model: separation, alignment and cohesion. L8
Buffer geometry
In three.js, a shape stored as arrays of per-vertex numbers. T2
Café wall illusion
Parallel mortar lines between shifted rows of dark and light tiles look tilted. IL2
Cell noise
Noise built from the distance to the nearest scattered points. Also called Worley noise. TX2, SH2
Cellular automaton
A grid of cells, each updated from its neighbours by a fixed rule. L8
Chroma
How colourful a colour is, in OKLCH. Zero is grey. L11
Chromatic aberration
Colour fringes from reading the red and blue channels at slightly different positions. SH4
Circle packing
Filling an area with circles that do not overlap. L7
Clamp
Limit a value to a range. L1
Clipping
Cutting geometry at a boundary and keeping the inside part. L18
Collapse
In Wave Function Collapse, fixing a cell to one tile. L14
Colour ramp
A list of positions and colours that turns one number into a colour. TX2
Complex number
A point on the plane written as one number. Multiplying two rotates and scales. M2
Compositing mode
The rule by which new drawing combines with what is already on the canvas. L10, W1
Constraint
A rule that must hold: in a design, a margin or minimum size; in physics, a condition enforced by moving points. L10, L17
Contact sheet
Many outputs shown small, side by side, to judge a system as a whole. L10
Contradiction
In Wave Function Collapse, a cell left with no possible tile. L14
Contrast ratio
A measure from 1 to 21 of how different two colours are in lightness. L11
Corner pin
Warping an image by dragging its four corners, used in projection mapping. S5
Cornsweet effect
Two equal areas look different because of the shape of the edge between them. IL1
Cosine palette
A smooth colour ramp made from three out-of-phase cosine waves. L9
Curl noise
A flow field that follows the contours of noise, so nothing converges or spreads. L5
Curvature
How sharply a curve is turning at a point. M3

D to F

Delaunay triangulation
A way of joining points into triangles that avoids thin slivers. The partner of the Voronoi diagram. L18
Derivative
The rate at which something changes: its slope. M3
Design gallery
A page of results chosen to look as different from each other as possible, shown in place of sliders. S10
Determinant
One number for a matrix: the factor by which it changes area. Negative means mirrored, zero means collapsed. M6
Deterministic
Giving the same result every time for the same inputs. L1, L2
Differential equation
A rule for how something changes, solved by stepping forward in time. M4
Differential growth
A line that keeps lengthening but cannot cross itself, and so folds. L16
Diffuse light
The matt part of shading: brightest where the surface faces the light. TX4, SH3
Diffusion-limited aggregation
Growth by random walkers that stick where they touch a cluster. L16
Distribution
The pattern of how often random values fall where: uniform, bell-shaped, biased. L2
Dithering
Representing shades of grey with only black and white pixels. L13
Domain randomisation
Varying everything that should not matter in synthetic training images, so that a model learns only what does. S2, S10
Domain warping
Distorting the input of a function, often noise with more noise. L3
Donor file
A sliced file from which the printer's start and end G-code are taken. P5
Dot product
One number measuring how much two directions agree. M2
Double buffering
Reading from one grid while writing to another, then swapping. L8
Draw call
One request to the graphics system to draw something. Fewer is faster. L19, T3
Easing
A function that shapes progress so motion speeds up and slows down. L15
Edition
The set of prints of one work. Limited editions have a fixed, declared size. S8
Eigenvector
A direction that a matrix stretches without turning. The stretch factor is its eigenvalue. M6
Emergence
Large-scale structure arising from simple local rules. L8
Entropy
In Wave Function Collapse, how many options a cell still has. L14
Envelope
The shape of a note's loudness over time. S4
Erosion (simulated)
Carving a generated terrain by simulating water carrying soil downhill. S10
Euclidean rhythm
A number of hits spread as evenly as possible over a number of steps. S4
Euler integration
Stepping a simulation: velocity plus acceleration, position plus velocity. L5, M4
Expressive range
The spread of outputs a generator produces, seen by measuring thousands of them on two scales. S10
Extension
Blender's packaging format for add-ons since version 4.2. B4
Extrusion
In printing, pushing plastic through the nozzle; the E value in G-code. In modelling, giving a flat shape a height. P4, P2
fBm
Fractal Brownian motion: several layers of noise at rising frequency and falling strength. L3
Feedback
A shader reading the picture it drew on the previous frame. SH4
Field
A rule that gives a value for every point in space. L1
Fingerprint
A short number computed from data, which changes if the data changes at all. S9
Finite difference
Estimating a slope from two nearby values. M3
Flow field
A field of directions that particles follow. L5
Forward kinematics
Posing a chain of joints by multiplying each joint's matrix onto the one before. M6
Fourier series
Building any repeating shape by adding sine waves. M5
Fractal
A shape whose parts resemble the whole. L6
Fragment shader
A small program that computes the colour of one pixel. L9
Frequency
How fast a wave repeats, or how fine the features of noise are. In sound, pitch. L3, L4, S4
fwidth
A GLSL function giving how much a value changes from one pixel to the next. Used for edges exactly one pixel soft. SH1

G to L

G-code
The plain-text list of moves and settings that a printer or CNC machine runs. S3, P4
Gaussian
The bell curve: values clustered round a mean. Also a soft falloff with distance. L2, M1
Generative art
Art made by a system with some autonomy, usually including chance. L1
Geometry Nodes
Blender's node-based system for procedural modelling. B3
Golden angle
About 137.5 degrees: the turn that spreads points most evenly round a centre. L4
Gradient
The direction and steepness of a field's rise. Also a smooth blend between colours. M3, L11
Grain
Fine random texture added to break up flat digital surfaces. L10
Gyroid
A lattice surface defined by one trigonometric formula. S3, P3
Halftone
Tone represented by dots of varying size. L13
Hash
A function that scrambles an input into an apparently random but repeatable number. L2, L3
Hatching
Shading with parallel lines. L10, L18
Height map
A grid of heights, one per point: a field treated as a surface. L3, P2
Hermann grid
A grid of light streets on dark in which grey spots appear at the crossings. IL1
Hidden-line removal
Deleting the parts of lines that are behind nearer shapes. L18
Homogeneous coordinates
Adding a coordinate fixed at 1 so that a matrix can shift as well as rotate and scale. M6
HSL
Colour as hue, saturation and lightness. Convenient, but its lightness is not perceptual. L1, L11
Hybrid image
The broad shapes of one picture added to the fine detail of another. Distance chooses which is seen. IL4
Illusory contour
An edge that is seen where none is drawn, completed from aligned gaps in other shapes. IL2
Impossible object
A drawing in which every part is a possible corner but the whole cannot exist. IL4
Instancing
Drawing many copies of one shape efficiently, each with its own placement. T2, B3
Integral
A running total: accumulation over time or distance. M3
Interpolation
Finding values between known ones. See lerp. L1
Inverse matrix
The matrix that undoes another. It turns screen positions back into grid coordinates. M6
Iterated function system
A fractal made by applying randomly chosen shrinking transformations repeatedly. L6
Kerf
The width of material removed by a laser or cutter. S3
Kinetic depth effect
Flat dots moving as if on a turning object are seen as a solid. IL4
L-system
A grammar that rewrites a string, which a turtle then draws. L6
Lacunarity and gain
How much frequency grows and strength shrinks with each octave of fBm. L3
Laplacian
How different a cell is from the average of its neighbours. L8, M4
Lattice
A repeating grid of points: whole-number steps along two basis arrows. M6
Lerp
Linear interpolation: the value a fraction of the way from one number to another. L1
Linear combination
A sum of scaled things: arrows, colours or whole shapes. M6
Lissajous figure
The curve traced by two oscillations at right angles. L4
Lloyd relaxation
Repeatedly moving each seed to the centre of its Voronoi cell, evening out the spacing. L7
Lofting
Building a surface by joining outlines at successive heights. P2
Long-form generative art
Releasing an algorithm whose every output must stand as a finished work. L10
Loop (perfect)
An animation that returns exactly to its start in both position and motion. L15
Low-discrepancy sequence
Points that spread evenly without being random. M5

M to P

Map (range)
Rescale a value from one range to another. L1
MAP-Elites
A search that keeps the best output found in every cell of a map of measurements. S10
Marching tetrahedra
An algorithm that turns a 3D distance function into triangles. P3
Mask
A shape or image that decides where something may appear. L7, W1
Matrix
A small grid of numbers describing a transformation of space. M2, M6
Mesh
A 3D shape made of triangles or other flat faces. P2
Method of adjustment
Measuring an illusion by asking a person to adjust one thing until it matches another. IL2
Mipmap
A stored image at full, half, quarter size and so on, each properly blurred, to avoid aliasing. TX1
Mixed-initiative design
A tool in which a person and a generator share the work, with the tool guaranteeing the constraints. S10
Modifier
In Blender, an editable operation applied to an object's geometry. B2
Modulo
The remainder after division. Makes things wrap and repeat. L1
Noise
Smooth, repeatable randomness that depends on position. L3
Normal
The direction at right angles to a curve or surface. M3
Normal map
A surface's facing direction at every point, packed into red, green and blue. TX4
Normalise
Turn a value into a 0 to 1 fraction; or scale a vector to length 1. M1, M2
Octave
One layer of fBm noise. In music, a doubling of frequency. L3, S4
Offsetting
Moving an outline inward or outward by a fixed distance. L18
OKLCH
A colour space with perceptual lightness, chroma and hue. L11
Operator
In Blender, an action available in menus and from Python. B1, B4
Orthographic projection
Drawing 3D on a flat screen by ignoring depth. Parallel lines stay parallel. M6
Oscillator
Something that swings back and forth regularly: a sine wave, or a sound source. L4, S4
Overhang
Part of a print with nothing beneath it. Beyond about 45 degrees it needs support. P1
Palette
The limited set of colours a piece uses. L10, L11
Parameter
A value that controls a system: a dial. L1
Parameter sweep
A grid of outputs in which two parameters vary and everything else is fixed. S7
Parametric curve
A curve whose x and y are both functions of one parameter. L4
Particle system
Many simple moving points with birth, life and death. L5
Peripheral drift
Apparent motion in a still pattern of four repeated brightness steps, seen away from the centre of gaze. IL3
Perlin noise
Ken Perlin's gradient noise, the most widely used kind. L3
Perspective projection
Drawing 3D on a flat screen by dividing by depth, so that far things are smaller. M6
Phase
Where in its cycle a wave or a loop is. L4, L15
Phase space
A plot of a system's state, such as position against speed. M4
Phyllotaxis
The spiral arrangement of seeds and leaves, from the golden angle. L4
Ping-pong
Two images that take turns: one is read while the other is written, then they swap. SH4
Pixel sorting
Rearranging runs of pixels in order of brightness. L13
Poisson-disc sampling
Random points with a guaranteed minimum spacing. L7
Polar coordinates
A position given as an angle and a distance. L4
Post-processing
A shader applied to a finished picture: vignette, grain, tone curve and so on. SH4
Preflight
Checking a file for problems before sending it to a machine. P4
PRNG
Pseudo-random number generator: produces repeatable "random" numbers from a seed. L2
Procedural
Made by a procedure, a set of rules, instead of by hand. L1
Propagation
In Wave Function Collapse, following the consequences of a choice outward. L14

Q to S

Quadtree
A square repeatedly divided into four where more detail is wanted. L7
Quality-diversity search
Search for many good answers that are deliberately different from each other. S10
Quilting
Extending a texture by copying overlapping blocks and joining them along the path of least difference. TX3
Random walk
A path made of accumulated small random steps. L2
Raycasting
Finding what a line from the camera through a screen point hits. T3
Raymarching
Rendering a 3D distance function by stepping along rays. L9
Reaction–diffusion
Two interacting, spreading substances that form spots and stripes. L8
Recipe
The code version, seed and parameters that reproduce an output. S9
Recursion
A function that calls itself on a smaller problem. L6
Rejection sampling
Proposing at random and keeping only what passes a test. L7, M5
Resolution independence
Drawing in unit coordinates so the same piece renders at any size. L10
Reversed phi
A pattern that turns negative as it steps is seen moving the opposite way. IL3
Roughness
How matt or glossy a surface is at a point. It decides how tight the highlight is. TX4
Scale (music)
The subset of pitches a piece uses. S4
Scene graph
The tree of nested objects in a 3D scene. T1
Search-based generation
Generating by altering candidates and keeping the best, given a way to score them. S10
Seed
The number or text that starts a random sequence, and so identifies an output. L2
Self-similarity
Looking alike at different scales. L6
Shaping function
A function that bends a 0 to 1 value by another route. M1
Signed distance function
A function giving the distance to a shape's edge, negative inside. L9, P3
Simulated annealing
A search that accepts some bad moves at first and fewer as it cools, to avoid getting stuck. S10
Simultaneous contrast
A patch looks lighter on a dark ground and darker on a light one. IL1
Slicer
Software that turns a 3D model into layers and toolpaths. P1
Smoothing (input)
Moving a value part of the way toward its target each frame. S1
Smoothstep
A ramp from 0 to 1 that eases in and out. L3, L9
Socket
In Wave Function Collapse, an edge label; two tiles fit where sockets match. In Blender, a node's input or output. L14, B3
Soft shadow
A shadow with a blurred edge, estimated from how closely a ray toward the light misses an object. SH3
Space colonisation
Branches that grow toward unclaimed attraction points. L16
Spatial hash
A coarse grid of buckets that makes "what is near here?" fast. L7, L19
Specular light
The highlight: a reflection of the light source, tighter on smoother surfaces. TX4, SH3
Sphere tracing
Stepping along a ray by the distance to the nearest surface. The method behind raymarching. SH3
Split grammar
Rules that cut a shape into smaller labelled parts, repeating a part as many times as fit. S10
Stagger
Giving each element its own delay, so motion travels as a wave. L15
Stick
A constraint keeping two points a fixed distance apart. L17
Stippling
Shading with dots, denser where darker. L13, M5
STL
The simplest 3D file format: a list of triangles. P2
Strange attractor
The structure a chaotic system stays on without ever repeating. M4
Streamline
The path of a particle through a flow field. L5
Subdivision
Repeatedly cutting a shape into smaller pieces. L7
SVG
A vector image format: shapes described as text. L10, L18
Symmetry group
The set of transformations that leave a design looking the same. M2

T to Z

Tangent
The direction of travel along a curve. M3
Tau
A full turn in radians: twice pi, about 6.283. L1
Texture synthesis
Making more of a texture from a small sample of it. TX3
Tile
A small unit repeated or combined to cover an area. L2, L14
Toolpath
The route a pen, cutter or nozzle follows. S3, P5
Topology optimisation
Computing where material should go in a part, from its loads and a material budget. S10
Trace
The sum of the two diagonal numbers of a matrix. M6
Trait
A named, seed-chosen feature of an output in a generative collection. L10
Transform
Moving, rotating or scaling the coordinate system. L1
Truchet tile
A tile whose pattern connects with its neighbours however it is turned. L2
Turbulence
Octaves of noise added as absolute values, which gives sharp creases. TX2
Turtle
A pen with a position and a heading that follows drawing instructions. L6
Typed array
A compact block of raw numbers, faster than objects for large counts. L19
Uniform
In a shader, a value passed in from outside. In randomness, equally likely everywhere. L9, L2
Unit coordinates
Positions as fractions from 0 to 1 instead of pixels. L10
UV coordinates
A position on a surface, from 0 to 1 each way, used to look up a texture. TX1
Value noise
Noise made by smoothly blending random values at grid points. L3
Vector
A pair or triple of numbers read as a direction with a length. Also: an image made of shapes, not pixels. L5, M2
Velocity
How much position changes each step. L5
Verlet integration
Simulating motion from the current and previous positions only. L17
Vertex shader
A program that decides where each vertex of a 3D shape appears. T3
Vignette
Darkening toward the corners of a picture. SH4
Volumetric flow
The volume of plastic a printer extrudes per second. Its real speed limit. P1
Voronoi diagram
The division of space into regions nearest to each of a set of seeds. L7
Wang tiles
Square tiles with coloured edges, laid so that touching edges match. A small set covers a plane without repeating. TX3
Watertight
A mesh with no holes: every edge shared by exactly two faces. P2
Wave Function Collapse
An algorithm that fills a grid with tiles so that every neighbour fits. L14
Web worker
A second thread for heavy work, so the page stays responsive. L19
Weighted choice
Picking from a list where some options are more likely than others. L2
White's illusion
Grey blocks set into black stripes look lighter than the same grey set into white stripes. IL1
Winding order
The direction in which a face's corners are listed, which tells the outside from the inside. P2
