Cheat Sheet

The formulas and code idioms of the course on one page. It prints well: use your browser's print command.

Everyday maths

lerp(a, b, t)   = a + (b - a) * t
norm(v, a, b)   = (v - a) / (b - a)
map(v, a,b,c,d) = c + (d - c) * (v - a) / (b - a)
clamp(v, lo, hi)= Math.min(hi, Math.max(lo, v))
smoothstep(t)   = t * t * (3 - 2 * t)
fract(x)        = x - Math.floor(x)
TAU             = 2 * Math.PI          // a full turn
degrees → radians: d * Math.PI / 180

Shaping a 0–1 value

t * t                 // ease in
1 - (1 - t) ** 2      // ease out
t ** p                // p < 1 early, p > 1 late
Math.sin(t * Math.PI) // up and back down
Math.floor(t * n) / n // n steps
Math.exp(-d*d / (s*s))// bell: 1 at d = 0, fading
Math.exp(-k * t)      // decay

Circles and angles

x = cx + Math.cos(a) * r
y = cy + Math.sin(a) * r
angle  = Math.atan2(dy, dx)
length = Math.hypot(dx, dy)
golden angle = Math.PI * (3 - Math.sqrt(5))
// evenly round a circle:
for (i = 0; i < n; i++) a = i / n * TAU
// phyllotaxis:
a = i * golden;  r = c * Math.sqrt(i)

Vectors

len = Math.hypot(x, y)
unit      = [x / len, y / len]
from A to B = [bx - ax, by - ay]
perpendicular = [-y, x]            // quarter turn
dot = ax * bx + ay * by   // unit vectors: 1 same, 0 square
rotate by a:
  [x*cos(a) - y*sin(a), x*sin(a) + y*cos(a)]

Matrices

apply [a b; c d]:  x' = a*x + b*y;  y' = c*x + d*y
det = a*d - b*c     // area factor; < 0 mirrored; 0 collapsed
inverse = [d -b; -c a] / det
grid point = i * e1 + j * e2       // basis e1, e2
cell under mouse = floor(inverse * (mouse - origin))
with a shift:  x' = a*x + b*y + tx  // ctx.setTransform
chain: M = parent * rotate * translate * scale
perspective:  sx = x * f / depth;  sy = y * f / depth
eigenvalues = (tr ± sqrt(tr*tr - 4*det)) / 2,  tr = a + d
blend: w1*A + w2*B + w3*C,  w1 + w2 + w3 = 1

Motion

// Euler (Lesson 5)
v += a;  v *= 0.98;  p += v;

// Verlet (Lesson 17)
vx = (x - px) * 0.99;  px = x;  x += vx + ax;

// stick between a and b, rest length L
d = Math.hypot(b.x - a.x, b.y - a.y);
fix = (d - L) / d / 2;
a.x += dx * fix;  b.x -= dx * fix;   // and y

// follow with smoothing
value += (target - value) * 0.1;

Animation

phase = (time % LOOP) / LOOP;      // 0 to 1
a = phase * TAU;
Math.sin(a * k)                    // k whole: loops cleanly

Distance functions

circle : length(p) - r
box    : q = abs(p) - b;
         length(max(q, 0)) + min(max(q.x, q.y), 0)
union  : min(a, b)        intersect: max(a, b)
subtract: max(a, -b)      shell: abs(a) - t
smooth union:
  h = clamp(0.5 + 0.5 * (b - a) / k, 0, 1)
  mix(b, a, h) - k * h * (1 - h)
repeat : fract(p) - 0.5
edge   : 1 - smoothstep(0, 0.01, d)

G-code (P1S)

bed 256 x 256, Z to 250, avoid front-left 18 x 28
G1 X.. Y.. E.. F..   // F is mm per MINUTE
M83                  // relative extrusion
bead area = (w - h) * h + PI * (h / 2) ** 2
E = area * length / 2.405      // 1.75 mm filament
flow = area * speed            // keep under the limit
M104 nozzle  M140 bed  M106 P1 S0-255 fan
M400 U1 pause

Reuse the slicer's start and end sequences. Preflight everything.
