A course in nineteen lessons, with sections on maths, 3D, Blender, printing and the web

Procedural Art

You write the rules; the computer makes the picture. Nineteen lessons take you from a first rectangle to finished, fast, well-crafted generative work, and each one ends with a piece you build yourself. Further sections cover the maths, special topics, 3D printing, three.js, Blender and web design.

How the course works

  1. Read the lesson. Every example on the page is live. Edit the code beside the picture and press Ctrl + Enter (or Run). Changing numbers and watching what happens is the fastest way to learn this subject.
  2. Build the challenge. Each lesson ends with a brief, a list of requirements and some hints, but no solution. Open the matching file in the challenges folder in a code editor, write your sketch, and refresh the browser to see it.
  3. Check yourself. Each challenge has a short checklist. When every item is true, move on.

Everything is plain JavaScript drawing on an HTML canvas. There is nothing to install: double-click index.html and you are running. A code editor such as VS Code makes the challenges more comfortable, but Notepad works.

The helper library

The examples use a small library called PA, in assets/pa.js. Nothing in it is magic: Lessons 2, 3 and 9 build its main parts from scratch before you start relying on them. You may use it in every challenge.

CallWhat it gives you
PA.rng(seed)A random function R() returning 0–1. The same seed always gives the same sequence. It also has R.range(lo, hi), R.int(lo, hi), R.pick(array), R.chance(p), R.gauss(mean, sd), R.weighted(items, weights) and R.shuffle(array).
PA.noise(seed)Smooth noise. N.get(x, y, z) and N.fbm(x, y, { octaves, lacunarity, gain }) both return 0–1.
PA.lerp(a, b, t)The value a fraction t of the way from a to b.
PA.map(v, a, b, c, d)Rescales v from the range a–b to the range c–d.
PA.clamp(v, lo, hi), PA.smoothstep(e0, e1, x), PA.dist(x1, y1, x2, y2), PA.fract(x), PA.TAUEveryday maths. TAU is a full turn, 2π.
PA.hsl(h, s, l, alpha)A CSS colour from hue (0–360), saturation and lightness (0–100).
PA.mix(hexA, hexB, t)A blend of two #rrggbb colours.
PA.cosPalette(t, a, b, c, d)A smooth colour ramp (see Lesson 9). PA.cosPaletteRGB returns [r, g, b] for pixel work.
PA.palettesFour small palettes: dusk, citrus, riso, mono. The first colour of each is the background.

Inside a live example

Example code on the lesson pages receives a few ready-made variables: ctx (the drawing context), W and H (the canvas size, 600 × 600 unless stated), mouse (x, y, down, active), PA, and loop(fn), which calls fn(seconds, frame) on every animation frame. The special topics also use keys (the keys currently held, after you click the canvas) and ui, which adds sliders, text boxes and buttons under the canvas. In the challenge files you set these up yourself; each starter shows how.
