3D Printing 2

Models from Code

A 3D model is a list of triangles. If your code can produce points in space, it can produce a printable object. This lesson builds meshes by hand, then from height maps and stacked outlines, and exports them as STL files that Bambu Studio opens directly.

What a mesh is

A printable model is a closed surface made of triangles. Nothing else: no curves, no solids, no units. Three rules make a pile of triangles into something a slicer accepts.

  1. Watertight. Every edge is shared by exactly two triangles. No holes, no loose flaps, no surfaces with zero thickness.
  2. Consistently facing. Each triangle has an outside. It is the side from which its three corners run anticlockwise. All triangles must agree.
  3. Real size. The numbers are taken as millimetres. Decide your dimensions in millimetres before writing anything else.

In these lessons a mesh is an array of triangles, each triangle three points, each point [x, y, z] with Z up. A helper called MESH (in assets/mesh.js, short enough to read) draws a preview, checks the rules above, and writes the STL file. In the preview, a triangle facing the wrong way is drawn red.

The STL file

STL is the simplest 3D format there is: a count, then for each triangle a direction and three corners. It stores no units, colours or names. Written as text it looks like this:

solid box
  facet normal 0 0 1
    outer loop
      vertex 0 0 20
      vertex 40 0 20
      vertex 40 30 20
    endloop
  endfacet
  …
endsolid box

The compact binary version holds the same numbers and is what MESH.stl writes. Bambu Studio also reads 3MF, a newer format that adds units, colours and several objects per file. STL is enough for everything in this course.

Height maps: a field becomes a relief

The quickest route from 2D procedural work to a 3D object is the height map. Take a grid of points, and raise each one by the value of a field. Every 2D technique in this course gives you a field: noise, a distance function, a reaction–diffusion pattern, a wave simulation.

A sheet of triangles is not printable, because it has no thickness. To make it a solid, the height map needs a flat bottom and four side walls joining the two. That is exactly what the function below builds, and it is the same code as MESH.heightfield.

Resolution is a real decision. One cell per millimetre is plenty: the nozzle cannot draw detail finer than its own 0.4 mm width, so a finer grid only makes the file larger. A tile like this has no overhangs at all, so it prints without support.

Patterns in relief

The same function turns any flat pattern into a tactile object: coasters, stamps, texture tiles, embossed signs. Give the pattern two levels and a smooth ramp between them. The ramp matters. A perfectly vertical step is fine to print, but a slight slope hides layer lines and releases from the bed more cleanly. A lithophane is this same idea with the height taken from an image's darkness: printed thin in white plastic and lit from behind, thick areas look dark and thin areas bright.

Lofting: stacked outlines

The second general method builds an object from the bottom up, as the printer does. Describe the outline at each height as a ring of points, then join each ring to the one above with a band of triangles. Close the bottom ring and the top ring with flat caps and the result is watertight. This is called lofting.

Since the outline can be any function of height and angle, lofting covers vases, lampshades, bottles, columns, bowls and horns. The design is a single function radius(v, a), where v runs from 0 at the base to 1 at the top and a is the angle round the axis. The polygonal vase below adds a twist: the angle is offset as height increases.

Solid model, hollow print. This vase is exported as a solid plug, not a thin shell. That is deliberate. In Bambu Studio, turn on Spiral vase mode (under Others → Special mode). The slicer then prints only the outer skin as one continuous rising spiral, with a solid bottom, giving a seamless hollow vase. For a vase with a thicker wall, set top layers and infill to zero instead and choose the number of wall loops.

Hand-built meshes get difficult when shapes must be joined, cut or hollowed, because the triangles of two objects do not line up. For that work use the implicit method of the next lesson, or a tool that performs "boolean" operations for you: OpenSCAD and CadQuery (both driven by code), Blender (see the Blender section), or the slicer itself, which can merge overlapping parts.

Checking a model

  • In code: MESH.check(tris) counts open edges, measures the size and volume, and detects an inside-out mesh.
  • In Bambu Studio: a warning icon appears beside an object with errors, and the slicer offers to repair it. Do not rely on the repair. Fix the generator.
  • In the slice preview: scrub through the layers. Missing walls or unexpected gaps mean a geometry problem. Check the printed size shown in the object list.

Key ideas

  • A model is triangles that form a closed surface, all facing outward, measured in millimetres.
  • Anticlockwise corners, seen from outside, mark the outside.
  • A height map plus a bottom and four walls turns any 2D field into a solid.
  • Lofting joins outlines at successive heights. One radius function is the whole design.
  • Grid resolution finer than the nozzle width adds file size, not detail.
  • Check watertightness and size in code before opening the slicer.

3D printing challenge 1

An Object from a Function

Design a useful, printable object whose shape comes from a function you wrote, and take it as far as a sliced preview in Bambu Studio.

Choose one

  • Relief tile or coaster from a field of your own: a pattern from an earlier lesson, a map of somewhere imaginary, or a lithophane of a generated image.
  • Lofted vessel: a vase, planter, pen pot or lampshade from your own radius function.

Requirements

  • All sizes in millimetres, as named constants, and the object fits the P1S: within 256 × 256 mm and 250 mm tall.
  • MESH.check reports a watertight mesh that is not inside out.
  • The generator enforces at least two print rules and reports them: for example a maximum wall lean of 45°, a minimum base thickness, a minimum feature width of 0.8 mm.
  • Seeded, with at least five seeds giving valid objects.
  • A key press downloads the STL, named after the seed.
  • You have opened the STL in Bambu Studio, confirmed the size, sliced it, and noted the estimated time and filament in a comment.

Hints

  • Build your own mesh code for at least one part. Use the helpers for the rest.
  • If the lean check fails for some seeds, reduce the amplitude until it passes instead of letting it through.
  • For a vessel, remember spiral vase mode. For a tile, no support is ever needed.

You are done when

  • The slicer shows no warnings and the size you intended.
  • You would be willing to start the print.
