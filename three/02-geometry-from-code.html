Geometry from Code

The built-in boxes and spheres only go so far. Procedural 3D means making your own geometry: surfaces from functions, thousands of copies placed by rule, and clouds of points. This lesson covers the four ways to put generated data on the graphics card.

What a geometry is

A BufferGeometry is a set of flat arrays of numbers, called attributes, with one entry per vertex:

position
Three numbers per vertex: x, y, z. The only attribute that is required.
normal
The direction the surface faces at that vertex, used for lighting. three.js can compute it for you.
color
Optional red, green, blue per vertex. The colours blend across each triangle.
uv
Optional texture coordinates.

Triangles are then described by an index: a list of vertex numbers, three per triangle. Sharing vertices between triangles this way keeps the data small and makes the surface smooth. As in the 3D printing lessons, the three corners of a triangle run anticlockwise when seen from its front.

A surface from a height function

The most useful hand-built geometry is the grid: rows and columns of vertices, with two triangles per square. Give each vertex a height from a field and it is a terrain. Give it a colour by height and it is a map. This is Lesson 3's noise terrain, now a real surface that light falls across.

Try it: remove flatShading: true for a smooth surface. Lower SEG to 30 for a deliberately faceted look.

Parametric surfaces

The grid does not have to stay flat. A parametric surface takes the two grid coordinates, u and v, each from 0 to 1, and maps them through a formula to a point in space. The grid indexing is identical; only the position function changes. Spheres, tori, shells, knots and vases are all one function each.

The seashell below combines two ideas from the maths section: a tube swept round an axis (polar coordinates), growing by a constant ratio as it goes (the exponential of Maths 1).

Instancing: one shape, thousands of times

Lesson 1's advice to share a geometry between meshes still leaves the graphics card drawing each mesh separately, which becomes slow beyond a few thousand. Instancing draws all the copies in one call. An InstancedMesh has a single geometry and material and a list of transforms, one per copy, each a position, rotation and scale. A hundred thousand objects is realistic.

The routine is always the same: move a throwaway helper object to where a copy should be, then store its transform. Here five thousand spikes sit on a sphere, placed by the golden angle from Lesson 4 so that they are evenly spread, and each one's length follows animated 3D noise.

Points

For particle systems and density images, skip triangles altogether. A Points object draws one dot per vertex. Hundreds of thousands are cheap. With additive blending, where overlapping dots add their brightness, a cloud of points glows where it is dense, exactly like the density plot in Maths 4.

The example runs the Lorenz system from Maths 4 and keeps every position it visits, so the strange attractor can finally be seen as the three-dimensional object it is.

To animate a custom geometry, change the numbers in its position attribute and set geometry.attributes.position.needsUpdate = true. For anything heavy, move the animation into a shader instead, which is the subject of the next lesson.

Key ideas

  • A geometry is arrays of per-vertex numbers plus an index listing the triangles.
  • A grid of vertices with a height function is a terrain. With a position function it is any parametric surface.
  • computeVertexNormals supplies lighting directions. flatShading gives facets.
  • Instancing draws thousands of copies in one call: set a transform per copy.
  • Points with additive blending make glowing density clouds.
  • Tell three.js when you change data: needsUpdate = true.

Practice

Three exercises

  • Your own surface. Write a new (u, v) function for T2.2: a torus knot, a vase with a wavy rim, or a Möbius band. Colour it by curvature or by height.
  • Grass. Scatter twenty thousand instanced blades over the terrain of T2.1, only where the ground is grass, leaning with a noise-driven wind.
  • Flow in 3D. Turn Lesson 5's flow field into three dimensions: trace a few hundred streamlines through a 3D noise field and draw them as Line objects.
