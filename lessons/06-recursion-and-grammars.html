Lesson 6

Recursion, Fractals and L-systems

A branch looks like a small tree. A coastline looks the same from a plane as from a cliff. Shapes built from smaller copies of themselves are called fractals, and the way to draw them is a function that calls itself.

Recursion

A recursive function solves a problem by doing a small piece of it and then calling itself to do the rest on a smaller scale. Every recursive function needs two parts:

  • a recursive step, where it calls itself with a smaller problem, and
  • a base case, where it stops. Leave it out and the function calls itself until the browser gives up.

The usual way to guarantee a stop is to pass a depth number that goes down by one on each call.

Recursion grows fast. With two calls per level, depth 6 draws 127 circles. With four calls per level it draws 5,461. Each extra level multiplies the work, so raise depth one step at a time.

Fractal trees

A tree is a branch with smaller trees on the end of it. Written as code that sentence is almost the whole program. The strictly regular version looks artificial, so each child branch gets a random angle and a random length ratio: structure from recursion, life from Lesson 2.

Try it: narrow the angle range to ±0.25 for a poplar, widen it to ±1.1 for a thorn bush. Add a constant to every angle to make the wind blow.

Replacing lines with shapes

Another family of fractals starts with a simple shape and repeatedly replaces every straight segment with a more detailed one. The Koch curve replaces each segment with four shorter ones that include a triangular bump. Three Koch curves joined make the Koch snowflake: a shape with a finite area and, in the limit, an infinitely long outline.

Fractals from repeated random jumps

There is a quite different route to a fractal. Take a handful of simple transformations, each of which shrinks and shifts the whole plane. Start at any point, pick one transformation at random, apply it, plot the result, and repeat tens of thousands of times. The points settle onto a shape that is made of shrunken copies of itself. This is an iterated function system. Michael Barnsley's fern uses four transformations: one for the stem, one for the main body (a slightly smaller, slightly rotated copy of the whole fern), and one each for the lowest left and right leaflets.

Try it: change 0.04 and -0.04 in the second rule to 0.1 and -0.1. That one pair of numbers controls how much the fern curls.

L-systems: grammar that grows

In 1968 the biologist Aristid Lindenmayer devised a way to describe plant growth as text rewriting. An L-system has:

An axiom
The starting string, for example X.
Rules
Replacements applied to every character at once, for example F → FF.
Generations
How many times to apply the rules. The string grows quickly.

The finished string is then read as instructions for a turtle, a pen with a position and a heading:

SymbolTurtle action
FMove forward, drawing a line
+ and -Turn right or left by a fixed angle
[Remember the current position and heading (start a branch)
]Go back to the last remembered state (end the branch)
Anything elseNo drawing. Symbols like X exist only to control growth.

The bracket pair is what makes branching possible. Remembered states are kept on a stack: [ pushes, ] pops.

The rule string is the plant's genetic code. Small edits give entirely different species. Two extensions matter in practice:

  • Stochastic L-systems give a symbol several possible replacements, chosen by weighted chance, so every plant from the same grammar is different.
  • Parametric L-systems attach numbers to symbols, so that segments can get shorter and thinner as they are generated.

The Mandelbrot set

The most famous fractal comes from asking one question about every point of the plane. Take the point as a constant c, start with z = 0, and repeat z = z² + c. Does z stay small for ever, or shoot off? Points where it stays small are in the set and are painted black. The others are coloured by how many steps they took to escape. All of its endless detail comes from that single line.

Key ideas

  • Recursion is a step plus a base case. Depth controls detail, and cost multiplies with every level.
  • A fractal is self-similar: its parts resemble the whole.
  • Strict recursion looks mechanical. Randomising angles, ratios and branch counts makes it look grown.
  • An iterated function system builds a fractal by applying randomly chosen shrinking transformations over and over.
  • An L-system separates growth (rewriting a string) from drawing (a turtle reading it). Brackets and a stack give branching.

Common mistakes

  • No base case, or a depth that never decreases.
  • Too many L-system generations. The string can reach millions of characters; print its length while you experiment.
  • Unbalanced brackets in a rule, which makes stack.pop() fail.
  • Using the same line width at every depth, which flattens the image. Taper it.

Challenge 6

The Grammar Garden

Write your own L-system engine and use it to grow a garden: several species of plant, each defined by a grammar you designed, planted along a ground line from a single seed.

Requirements

  • A reusable engine: one function that expands an axiom through rules, and one that draws a string with a turtle.
  • Stochastic rules. A symbol may have several replacements with weights, for example F: [['F[+F]F', 2], ['F[-F]F', 2], ['FF', 1]].
  • At least three species, each with its own rules, turn angle and step length, and visibly different in character.
  • A garden of at least seven plants of varying size along a ground line, all from one seed.
  • Line width tapers with branch depth. The length of the turtle's stack tells you how deep you are.
  • Something is drawn at branch tips: a leaf, a flower or a berry.

Hints

  • Get the engine working with the grammar from example 6.5 before inventing your own.
  • A tip is the position just before a ]. Add a new symbol of your own, such as L, to the rules wherever a leaf should appear, and teach the turtle to draw it.
  • Use ctx.translate and ctx.scale to place each plant, so the turtle can always start at the origin.
  • Because line width changes, stroke each segment separately instead of building one long path.

Stretch goals

  • Add a small random wobble to every turn so no two branches are quite parallel.
  • Make segments shorter with depth.
  • Animate growth by drawing a little more of the string each frame.

You are done when

  • You can add a fourth species by writing only a new rule set, without touching the engine.
  • Two plants of the same species in the same garden are recognisably related but not identical.

References and further reading
