Lesson 12

Typography and Text

Letters are the most recognisable shapes there are, which makes them excellent raw material. This lesson treats text three ways: as content to lay out by rule, as marks to place along paths, and as geometry to fill, sample and distort.

Text on the canvas

Three calls do everything. ctx.font sets the typeface with a CSS font string such as '700 48px Georgia'. ctx.fillText(text, x, y) draws it. ctx.measureText(text).width tells you how wide it will be before you draw it, and that measurement is what makes layout by rule possible.

Two settings control what the x and y refer to: ctx.textAlign (left, center, right) and ctx.textBaseline (alphabetic, the default, or middle, top).

These examples use fonts every computer has: Georgia, Arial and a monospace face. A web font works the same way once it has loaded.

Fitting type to a block

The classic typographic poster sets each line at whatever size makes it exactly fill the width. Measure the line at a known size, divide the width you want by the width you got, and scale the font by that ratio. Short words come out enormous and long ones small, which gives an automatic hierarchy.

Layout grids

Beyond a single block, typographic layout is the subdivision of Lesson 7 with rules about what goes where. Special Topic 2's poster system showed the pattern: divide the page into blocks on a grid of halves and thirds, give the largest suitable block to the headline, fit the type to it, and fill the rest by weighted choice. The constraint that makes layouts look designed is alignment: everything starts on one of a small number of shared lines.

Text on a path

To run text along a curve, place one letter at a time. Each letter sits at a distance along the path equal to the widths of all the letters before it, and is turned to follow the curve's direction there. That needs the two tools from Maths 3: arc length, to find the point a given distance along, and the tangent, to find the angle.

Letters as geometry

A letter is a shape, and any technique that works on shapes works on it. The simplest way to get at that shape is to draw the text onto a hidden canvas and read its pixels. Where the pixel is opaque you are inside a letter. That gives you an inside(x, y) test, which is exactly what Lesson 7's packing needed.

From that one test come most generative type treatments: letters filled with packed circles, stippled, grown over by a flow field that only runs inside them, or used as a mask for any pattern.

For vector work such as plotting, pixels are not enough: you need the outlines themselves. Font libraries (opentype.js is the usual one) read a font file and give each glyph as a path of lines and curves, which you can then offset, hatch or clip with the tools of Lesson 18.

Type in motion

Once text is an image, it can be cut up and moved like one. Kinetic typography often does nothing more than draw the same text in thin slices, each shifted by a wave. The canvas's nine-argument drawImage copies any rectangle of a source to any rectangle of the destination, which is all a slice is.

Key ideas

  • measureText tells you a line's width in advance. Layout by rule depends on it.
  • To fill a width, scale the font by wanted width over measured width.
  • Text on a path is one letter at a time: arc length for position, tangent for angle.
  • Text drawn to a hidden canvas gives an inside test, and from it any fill or packing.
  • Text as an image can be sliced, shifted and recombined.
  • Legibility is a dial. Decide how much of it each piece needs.

Common mistakes

  • Measuring with one font and drawing with another. Set ctx.font before every measurement.
  • Using a web font before it has loaded, which silently draws a fallback. Wait for document.fonts.ready.
  • Distorting text until nobody can read it, when the words mattered.

Challenge 12

The Type Poster

Make a typographic poster generator: give it a short phrase and a seed, and it produces a finished poster in which the letters themselves are the image.

Requirements

  • The phrase is an input. The poster re-composes itself for any phrase from one word to six.
  • A layout rule that fits the type to the page: every line is sized by measurement, with a margin, and nothing overflows.
  • The letters are filled or built by a generative treatment that uses an inside test: packing, stippling, hatching or flow lines.
  • At least one line of text runs along a path.
  • A palette with a contrast check from Lesson 11.
  • The phrase stays readable from across a room.
  • Seeded, with a key for a new seed and a key to save a PNG.

Hints

  • Do the layout first with plain filled text. Add the treatment only when the layout works for short and long phrases.
  • Sample the hidden canvas once per draw, not once per test.
  • Thin letter strokes cannot hold large circles. Choose a heavy typeface, or scale the marks to the stroke width.

Stretch goals

  • Animate the treatment so the poster loops.
  • Use opentype.js to get true outlines and export an SVG for a plotter.

You are done when

  • Five different phrases each give a poster you would print.
  • Someone can read the phrase in two seconds.
